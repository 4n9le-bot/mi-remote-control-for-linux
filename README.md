# 小米语音遥控器适配 Linux 电脑

让小米蓝牙遥控器 2 Pro 在 Linux 电脑上用来语音输入和控制按键。

按住遥控器的语音键说话，松开后自动转成文字，输入到当前应用。
默认通过 [Voxtype](https://github.com/peteonrails/voxtype) 识别，也可以选择 OpenAI、火山引擎或阿里云在线识别。

目前支持小米蓝牙遥控器 2 Pro（`2717:32b8`）。

## 使用前

- Linux 桌面使用 BlueZ 蓝牙和 Fcitx 5 输入法。
- 遥控器已通过系统蓝牙设置与电脑配对。
- 安装 `fcitx5-commit`，用于将识别结果输入当前应用。
- 默认识别方式需要安装 Voxtype；选择在线识别则需要对应服务的凭据和系统密钥环。

## 安装

从源码构建需要 Rust 1.85 或更新版本、GTK4 / Libadwaita 开发库及 Debian 打包工具。

```sh
scripts/build-deb.sh
sudo apt install ./target/debian/atvv-bridge_*.deb
```

安装后，断开并重新连接遥控器。从应用菜单打开 **ATVV Voice Bridge** 即可使用；以后登录桌面时会自动启动。

## 使用

1. 打开需要输入文字的应用，将光标放到输入位置。
2. 按住遥控器语音键说话。
3. 松开语音键，等待文字输入。

在应用的「语音识别」页面可以切换识别服务。使用在线识别时，填写所需凭据并点击「保存并使用」；凭据保存在系统密钥环中。在线识别会上传录音，可能产生服务费用。

识别失败时会保留录音文件，状态页会显示错误和文件路径。可以重新录音，或手动切回 Voxtype。阿里云单次录音最长 60 秒。

在 **Button Mapping** 页面可以修改方向、确认、返回、音量等按键的作用。保存后需重新连接遥控器。电源键默认禁用，语音键专用于语音输入。

有托盘时，关闭窗口仍可继续使用；停止程序请在托盘菜单选择 **Quit**。

## 卸载

```sh
sudo apt remove atvv-bridge
```

卸载后重新连接遥控器，恢复原有按键行为。
