# 小米蓝牙遥控器 2 Pro 适配顺(mi-remote-control-for-linux) 

实现一个 Linux 用户态 Rust 桥接程序，使支持 ATVV 私有 BLE 语音协议的遥控器能够作为 `voxtype` 的语音输入设备。
